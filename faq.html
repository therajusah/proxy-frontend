how it works

A relay is a boundary, not a disguise.

RelayNorth is designed to make a browser request easier to understand: your tab talks to us, we talk to an approved origin, and the response comes back through the same session.

Does it protect my whole device?

No. It covers the browser tab using the relay. Other apps, browser tabs, DNS requests, and direct resources may use your normal connection.

Does it make me anonymous?

No service should promise that. The approved origin sees our relay address, but login accounts, cookies, browser behavior, direct requests, and other signals can still identify a visitor.

Why are destinations restricted?

This development build only accepts owned test origins so we can validate session isolation, response rewriting, limits, and abuse handling before any broader access is considered.

What can I test?

Run the included owned test origin on port 9001, then use http://127.0.0.1:9001/ from the home form. The local exception is for development only.

Need help or want to report abuse?

Use the contact address published with the deployment. Include the session identifier only when it is necessary for investigation, and never send passwords or private content.
